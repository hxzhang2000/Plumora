## 二、中文名「观梅」释义

取自邵雍「观梅占」典故：北宋某年春，邵雍与客人漫步，见二雀争枝坠地，因而起卦，后果然应验。此典故是梅花易数「观物取象、以象占断」最经典的方法论出处。

| 维度 | 说明 |
| --- | --- |
| 出处 | 邵雍《梅花易数 · 观梅占》 |
| 语义 | 观物取象；观察外物之象以推断吉凶 |
| 优点 | 两字、有画面、典故明确，本项目最贴切的名称 |
| 注意 | 需与已有的「观梅」类排盘工具做区分，建议副标题加上品类词（如「观梅 · 梅花易数起卦」） |

备选（曾考虑，最终未采用）：心易、数往、知来、观物、拈花、雪香、疏影、一念、康节、未济、履霜、报数、掷梅、梅开。

## 三、英文名「Plumora」释义

| 维度 | 说明 |
| --- | --- |
| 构词 | Plum（梅） + -ora（拉丁抽象后缀，同 honor / memoria 词族），整体为造词 |
| 读法 | /ˈplʌmərə/，中文近似「普路-莫拉」 |
| 语义 | 保留“梅”的意象，同时获得品牌化的独占感 |
| 优点 | 造词、无既有词根冲突，跨类别商标可行性较好；柔和、适合长期品牌延展 |
| 淘汰候选（未采用） | Plum Oracle、Plum Fate、Guanmei、Mei、Sortes、Alea、Oraculum、Plumabet、Plumcast、Plumwise、Pluma、Plumform、Meiwei |
