## 一、核心结论（先看这七条）

| # | 结论 | 依据 |
| --- | --- | --- |
| 1 | **赛道正被 AI 解卦重塑**。2025—2026 年新出的易经类应用几乎全部绑定「AI 解读 + 连续追问 + 记忆」，一次性排盘已不是卖点 | YaoWise、Yilore、I Ching Action、梅花占卜（AI 版） |
| 2 | **我们的「纯离线 + 无账号 + 卦例本地留存」是硬差异化，但没人替我们说**。竞品讲隐私是为了给云端订阅做铺垫，我们是真的不联网，这点是产品事实而非营销话术 | 产品定位 vs. iChingLife「本地存储 + AI 助手」 |
| 3 | **汉字笔画起卦（含简繁切换）是明显的功能空位**。主流竞品主打时间 / 数字 / 铜钱 / 摇卦，把「笔画起卦」当成特色主打的极少 | 竞品功能逐条比对 |
| 4 | **「卦例应验标记」这个学习闭环，竞品普遍缺失**。多数只做「历史记录」，不做「验证结果」 | 梅花占卜仅约 50 笔上限记录；易爻只有存档 |
| 5 | **合规是双刃**：同行用 AI 生成白话解读赚快钱，同时踩 315 曝光与黑猫近千条投诉；我们不生成预测性结论，过审概率更高，但也就拿不到那条最赚钱的变现路径 | 测测 2026-03 舆情；App Store 4.3(b) 饱和品类 |
| 6 | **App Store 已把「算命类」列为饱和品类**。若做海外版，必须提供「显著不同的体验」而非又一个卦表 | 苹果 App Store 审核指南 4.3(b) 更新 |
| 7 | **国内厂商市场仍在专项清理封建迷信类**，品牌名「观梅」需与既有排盘工具做区分（详见 brand-naming.md） | vivo 快应用审核规范；应用市场专项治理 |

## 二、竞争格局总览

按产品形态把竞品分成四层，我们处在第 ① 层，但和第 ③ 层是同一批用户。

| 层级 | 形态 | 代表产品 | 变现 | 对我们的关系 |
| --- | --- | --- | --- | --- |
| ① | 纯排盘工具（离线 / 弱联网） | 观梅（我方）、iChingLife、I Ching - Authentic Divination | 免费 / 一次性付费 | **最贴近的直接竞品** |
| ② | 排盘 + 知识库（重内容） | 易爻、梅花易数（长沙顶策）、梅花占卜（AI 版） | 广告解锁 / 订阅 | 功能重叠最多 |
| ③ | AI 解卦 + 情绪陪伴 | YaoWise 爻知、Yilore、梅花占卜、I Ching Action | 订阅 / 内购 / 广告 | **最想抢我们用户的一层** |
| ④ | 综合命理娱乐大平台 | 测测、问真八字、大师奇门 | 付费咨询（抽成） | 不直接竞争，但定义品类认知与舆论 |

**一句话概括格局**：① 层产品极少且正在被 ③ 层吞并，② 层拥挤但同质化严重，③ 层钱多但合规风险高，④ 层是流量与舆论的放大器（负面舆情会外溢到整个品类）。

## 三、竞品逐一分析

### 3.1 iChingLife（Google Play，开发者：苏何）

| 维度 | 内容 |
| --- | --- |
| 定位 | 面向「普通人 + 深度学者」双层的易经工具箱 |
| 起卦 | 大衍法、铜钱法、略束法（日本略束）、抽签法；手动 / 自动双模式 |
| 隐私 | **无注册、不收集个人数据、卦例全部本地存储、无云存储** |
| 附加 | 内置 AI 易经助手；64 卦多路径检索（上下卦组合、阴阳爻切换、卦歌定位、关键词）；互动小游戏（画卦猜卦名）；京房纳甲、爻卦、易林、朱熹变卦法 |
| 变现 | Google Play 标注「含广告 + 内购」 |
| 优势 | 功能密度最高，学术向内容（纳甲 / 易林）是别人没有的深度 |
| 短板 | 有 AI 助手即意味着联网，与「隐私优先」叙事存在张力；界面偏专业，对新手不友好 |
| 威胁度 | **高** —— 是我们的第一对标，因为隐私立场最接近 |

### 3.2 I Ching - Authentic Divination（Google Play，开发商：日本 qooq 公司）

| 维度 | 内容 |
| --- | --- |
| 定位 | 严格复刻传统蓍草法的「正统」易经占卜 |

| 隐私 | 声明不收集任何数据 |
| 优势 | 内容深度与仪式感极强，开发者是日本团队，内容组织是教科书级 |
| 短板 | 全日文，中文用户门槛高；无卦例复盘体系，无学习模块 |
| 威胁度 | 中低（国内可直接忽略，海外版有参考价值） |

**矩阵读出来的三个空位**：

1. **FR-03 / FR-04 是空白地带** —— 竞品几乎不把「笔画起卦」「点数起卦」当核心卖点，我们把它做成 P0 反而稀缺（前提是笔画表要真的准，否则是负分）。
2. **「应验状态机」全域缺位** —— 没有任何一款产品做「未验 / 应验 / 未验中 / 不验」的四态复盘闭环，这是学习型产品的护城河。
3. **离线 + 无 SDK 只有 iChingLife 真做到了** —— 其他竞品讲隐私都是为了卖订阅，我们不需要讲，只需要把它做成事实。

## 五、差异化定位建议

| 维度 | 市面主流 | 观梅应该占据 |
| --- | --- | --- |
| 身份 | 会算卦的 AI | **能验证对错的易经教材** |
| 输出 | 一段白话解读（不可验证） | 规则陈述 + 原始卦象（可自行验算） |
| 记录 | 历史流水账 | 带结论与应验状态的实验笔记 |
| 数据 | 云端留痕，为下次订阅铺垫 | 全在本地，删掉就没了 |
| 商业化 | 订阅 / 广告 / 人工咨询 | 第一版不做；若做，只做文创与知识付费 |

**一句话定位（对外）**：一款只管算得准、不管算得神的梅花易数工具。

### 需要守住的三条

| 原则 | 说明 |
| --- | --- |
| 不生成预测性结论 | PRD 已有约定。这不只是合规，更是与 AI 类竞品的根本分野 |
| 不联网就不留痕 | 连崩溃上报都别做，否则「离线」叙事自相矛盾 |
| 算法正确性优先于功能数量 | 金标准算例（2026-08-15 午时 → 水风井、动爻 1、「梅花」→ 火地晋）必须长期回归测试 |

### 值得考虑的三个增强

| 增强 | 理由 | 优先级 |
| --- | --- | --- |
| 笔画表可自查（内置一个「笔画数查询 + 覆盖度」页面） | 笔画起卦的软肋是笔画数查不到，做成可自查能消解最大质疑 | 高 |
| 金标准算例内置为「示例卦例」 | 把可验证性做成产品体验的第一屏 | 中 |
| 卦例导出 + 导入 | 竞品易爻支持导入导出，我们若长期只有导出，换机场景会掉分 | 中 |
