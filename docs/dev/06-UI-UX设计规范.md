## 一、设计原则

1. **安静的水墨气质**：视觉基调取「宣纸、墨线、朱砂点」，克制的留白，不堆砌装饰。
2. **排盘即核心**：所有页面的信息密度服务于排盘可读性；卦符永远是一级视觉元素。
3. **规则陈述而非断言**：文案呈现「体用生克关系」等规则推导结果，不做预测性断言（合规要求，见 01 文档 §五）。
4. **单手可达**：核心操作（起卦按钮）位于拇指热区（屏幕下半部）。

## 二、信息架构与导航

```
观梅 App
├─ 起卦（默认 Tab，首页）
│   ├─ 方式选择器：时间 / 数字 / 汉字 / 声音（顶部分段控件，记忆上次选择）
│   └─ 各方式输入区 → 「起卦」主按钮
├─ 卦例（Tab 2）
│   ├─ 列表（时间倒序 + 搜索框 + 应验状态筛选）
│   └─ 卦例详情 = 排盘结果页复用 + 编辑能力
├─ 学习（Tab 3）
│   ├─ 起卦方法说明
│   ├─ 八卦类象速查
│   └─ 六十四卦速查
└─ 设置（右上角图标入口，非 Tab）
    ├─ 笔画标准 / 默认起卦方式 / 体用判定规则 / 主题 / 保留记录上限
    └─ 关于 / 隐私说明 / 免责声明
```

底部导航 3 个 Tab：起卦、卦例、学习。

│                              │
│  （方式对应的输入区）          │

│        午时 · 可手动修正」     │
│  数字：两个输入框              │
│  汉字：两个汉字输入框          │
│  声音：点按大按钮 + 计数       │
│                              │

│      ┌──────────────┐        │

### 3.2 排盘结果页（核心页面）

```
┌────────────────────────────────┐
│ ← 丙午年八月十五午时 · 时间起卦│
│                                │
│  本卦      互卦      变卦      │
│  ─────     ─────     ─────     │
│  ▄▄ ▄▄     ▄▄▄▄▄     ▄▄ ▄▄     │  ← 上爻(6)
│  ▄▄▄▄▄     ▄▄ ▄▄     ▄▄▄▄▄     │  ← 五爻(5)
│  ▄▄ ▄▄     ▄▄▄▄▄     ▄▄ ▄▄     │  ← 四爻(4)
│  ▄▄▄▄▄     ▄▄ ▄▄     ▄▄▄▄▄     │  ← 三爻(3)
│  ▄▄▄▄▄     ▄▄▄▄▄     ▄▄▄▄▄     │  ← 二爻(2)
│  ▄▄ ▄▄ ●   ▄▄▄▄▄     ▄▄▄▄▄     │  ← 初爻(1)，动爻圆点
│                                │
│  水风井    火泽睽    水天需    │  ← 卦名
│  坎上巽下  离上兑下  坎上乾下  │  ← 上下卦
│                                │
│ ┌────────────────────────────┐ │
│ │ 体用：体坎(水) · 用巽(木)  │ │
│ │ 关系：体生用（小凶）       │ │
│ │ 传统断法：小凶（主耗损）   │ │
│ └────────────────────────────┘ │  ← 生克结论卡
│                                │
│  ▸ 本卦卦辞  ▸ 动爻爻辞（初六）│  ← 可展开
│                                │
│  [保存卦例]  [查看类象]  [分享]│
└────────────────────────────────┘
```

> **本示意图对应金标准算例 A**（农历 2026 年八月十五午时，见 03 文档 §2.1）：
> 本卦水风井、互卦**火泽睽**、变卦水天需、动爻**初爻**（六爻自下而上第 1 爻）。
> 卦符与 HTML 原型 `docs/ui/观梅-Plumora-UI设计稿.html` 实测渲染结果逐爻一致。
> ⚠️ 示意图中的 `▄`、`●`、`·` 属 East Asian Ambiguous 宽度字符，在不同字体下占 1 或 2 列，右框线可能有 1–2 列偏移——**以内容为准，不要以框线为准**。

**硬性布局约定**：

| 项 | 约定 |
| --- | --- |
| 卦符绘制 | 六爻**自上而下**绘制：最上两行是上卦、最下是初爻；与阅读顺序一致（下爻 = 爻 1 在最底部） |
| 三卦并排 | 本卦（大）、互卦（小）、变卦（小），左中右排布，间距 16dp |
| 动爻标记 | 动爻右侧实心圆点（朱砂红），变卦中对应爻不再标点 |
| 体用标注 | 在本卦左右两侧以小字「体」「用」标注对应半卦（可选开关） |
| 结论卡 | 五行生克结论永远独立成卡，是结果页第二视觉焦点 |

### 3.3 卦例列表 / 详情

- 列表项：卦名 + 起卦时间 + 方式图标 + 所问之事（截断一行）+ 应验状态徽标。
- 详情 = 排盘结果页布局 + 顶部「所问之事」编辑区 + 底部操作（编辑备注 / 标记应验 / 删除）。
- 删除必须二次确认对话框。

### 3.4 学习页

- 起卦方法说明：五个可折叠章节（时间/数字/汉字/声音/随机），内容取自 03 文档规则，含示例。
- 类象速查：上卦选择器 + 类目 Tab（**人伦 / 天时 / 地理 / 身体 / 动物 / 静物 / 性情人事 / 方位 / 时令**，类目名称与 05 文档 §2.2 八卦类象表表头一致）。
- 六十四卦速查：8×8 宫格矩阵（上卦行 × 下卦列），点格进入卦详情。

## 四、视觉规范

### 4.1 色板（浅色主题）

| 语义 | 色值 | 用途 |
| --- | --- | --- |
| 背景 | #FAF7F0 | 宣纸底色 |
| Surface / 卡片 | #FFFFFF | 卡片、对话框 |
| 主文字 | #2B2B2B | 正文 |
| 次要文字 | #8A8578 | 注释、标签 |
| 墨线（主色） | #3A3A3A | 阳爻、主按钮、图标 |
| 朱砂（强调） | #B03A2E | 动爻标记、吉凶徽标、错误 |
| 青灰（辅助） | #6B7B8C | 阴爻断线视觉、次级按钮 |

深色主题：背景 #1C1A17、卡片 #26231F、主文字 #E8E2D5、墨线 #D8D2C4、朱砂 #C9564A。

### 4.2 字体

| 用途 | 字体 | 字号/行高 |
| --- | --- | --- |
| 卦名 / 标题 | 思源宋体（Noto Serif SC，随 APK 打包 SubSet） | 22sp / 1.3 |
| 正文 | 系统默认（HarmonyOS Sans / MIUI 字体兼容） | 15sp / 1.5 |
| 卦符 | 专用绘制（Canvas/自绘 Composable，**不依赖 Unicode 字体渲染**） | 线宽 4dp，断线缺口 8dp |

> 卦符用自绘组件 `TrigramGlyph`（三爻）与 `HexagramGlyph`（六爻）实现，保证所有 ROM 渲染一致；Unicode 卦符 ☰–☷ 仅用于次要场景。

### 4.3 图标与插画

- 线性图标风格，2dp 描边，与墨线同色。
- App 图标：朱砂底 + 白色梅花枝剪影（具体见品牌文档，另行设计）。

## 五、交互细节

| 场景 | 交互 |
| --- | --- |
| 起卦成功 | 结果页从底部滑入；卦符六爻自上而下**逐爻浮现**（每爻 80ms，共 ~480ms），动爻圆点最后弹入 |
| 保存卦例 | Snackbar「卦例已保存」，带「查看」动作 |
| 删除卦例 | 二次确认对话框，明确显示卦名与时间 |
| 声音起卦计数 | 每次点按按钮缩放动画 + 轻微触感反馈（HapticFeedback） |
| 数字输入 | 数字键盘，禁止负数/小数；超长输入实时提示上限 |
| 手动修正农历 | 时间起卦页点农历标签 → 底部弹层（农历日期 + 时辰选择器） |
| 错误状态 | 统一错误卡样式（青灰边框），文案给原因 + 建议（如「该字未收录笔画，请手动输入」） |

## 六、无障碍与适配

| 项 | 要求 |
| --- | --- |
| TalkBack | 卦符组件提供 contentDescription，如「本卦水风井，上卦坎下卦巽，第一爻动」 |
| 触控目标 | 最小 48dp × 48dp |
| 动效降级 | 尊重系统「减少动画」设置（AnimatorDurationScale） |
| 折叠屏/平板 | 结果页在展开态改为横向三栏（本/互/变卦各占一栏） |
| 字体缩放 | 支持 1.0–1.3 系统字体缩放不破版 |

## 七、文案规范

| 项 | 约定 |
| --- | --- |
| 品牌署名 | 统一「观梅 · Plumora」 |
| 断卦表述 | 「传统断法：小凶，主耗损」格式；禁用「你将会/必定/注定」 |
| 免责声明 | 首启声明页 + 关于页固定文案：「本应用仅供传统文化学习与研究使用。」 |
| 语气 | 简体中文，书面、克制，不使用网络语与感叹号堆叠 |
