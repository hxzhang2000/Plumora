## 一、设计原则

1. **安静的水墨气质**：视觉基调取「宣纸、墨线、朱砂点」，克制的留白，不堆砌装饰。
2. **排盘即核心**：所有页面的信息密度服务于排盘可读性；卦符永远是一级视觉元素。
3. **规则陈述而非断言**：文案呈现「体用生克关系」等规则推导结果，不做预测性断言（合规要求，见 01 文档 §五）。
4. **单手可达**：核心操作（起卦按钮）位于拇指热区（屏幕下半部）。
5. **一套设计令牌、两端渲染**：色板 / 字号 / 间距以本文件为唯一来源；Web 端落为 CSS 自定义属性，Android 端落为 Compose Theme（见 02 文档 §三）。

## 二、信息架构与导航

```
观梅 App
├─ 起卦（默认 Tab，首页）
│   ├─ 方式选择器：时间 / 数字 / 汉字 / 声音（顶部分段控件，记忆上次选择）
│   └─ 各方式输入区 → 「起卦」主按钮
├─ 卦例（Tab 2）
│   ├─ 列表（时间倒序 + 搜索框 + 应验状态筛选）
│   └─ 卦例详情 = 排盘结果页复用 + 编辑能力
├─ 学习（Tab 3）
│   ├─ 起卦方法说明
│   ├─ 八卦类象速查
│   └─ 六十四卦速查
└─ 设置（右上角图标入口，非 Tab）
    ├─ 笔画标准 / 默认起卦方式 / 体用判定规则 / 主题 / 保留记录上限
    └─ 关于 / 隐私说明 / 免责声明
```

底部导航 3 个 Tab：起卦、卦例、学习。

**导航形态随视口切换**（Web 端）：

| 视口宽度 | 导航形态 | 说明 |
| --- | --- | --- |
| < 900px | 顶部栏（标题 + 设置入口）+ **底部 3 Tab** | 与移动端一致，主按钮置于拇指热区 |
| ≥ 900px | **左侧固定侧边栏**（232px）+ 居中内容区（上限 1080px） | 桌面端利用横向空间，避免底部 Tab 在宽屏下的空疏感 |

断点与实现细节见 §6.2。信息架构本身不随视口变化——两端、两种视口下 Tab 集合与页面层级完全一致。

```
│ └────────────────────────────┘ │  ← 生克结论卡
│                                │
│  ▸ 本卦卦辞  ▸ 动爻爻辞（初六）│  ← 可展开
│                                │
│  [保存卦例]  [查看类象]  [分享]│
└────────────────────────────────┘
```

> **本示意图对应金标准算例 A**（农历 2026 年八月十五午时，见 03 文档 §2.1）：
> 本卦水风井、互卦**火泽睽**、变卦水天需、动爻**初爻**（六爻自下而上第 1 爻）。
> 卦符与 HTML 原型 `docs/ui/观梅-Plumora-UI设计稿.html` 实测渲染结果逐爻一致。
> ⚠️ 示意图中的 `▄`、`●`、`·` 属 East Asian Ambiguous 宽度字符，在不同字体下占 1 或 2 列，右框线可能有 1–2 列偏移——**以内容为准，不要以框线为准**。

**硬性布局约定**：

| 项 | 约定 |
| --- | --- |
| 卦符绘制 | 六爻**自上而下**绘制：最上两行是上卦、最下是初爻；与阅读顺序一致（下爻 = 爻 1 在最底部） |
| 三卦并排 | 本卦（大）、互卦（小）、变卦（小），左中右排布，间距 16dp |
| 动爻标记 | 动爻右侧实心圆点（朱砂红），变卦中对应爻不再标点 |
| 体用标注 | 在本卦左右两侧以小字「体」「用」标注对应半卦（可选开关） |
| 结论卡 | 五行生克结论永远独立成卡，是结果页第二视觉焦点 |

> 表中单位为 Android 侧基准（dp/sp）；Web 端取等值 CSS 长度（1dp ≈ 1px），并以 `clamp()` 随视口缩放。本卦在 Web 端为互卦/变卦的 **1.35 倍**尺寸，三卦并排在窄屏下自动缩为等宽三列。

### 3.3 卦例列表 / 详情

- **列表项主标题 = 卦例名称**（`recordTitle()`，取值规则见 04 文档 §2.8）：填了「所问之事」就以所问之事作标题，未填目标时回退到本卦卦名。名称单行截断（`text-overflow: ellipsis`），完整文本走原生 `title` 提示。
- 列表项副行：**标题已是卦名时不再重复一遍卦名**；标题是所问之事时保留「卦名 · 农历 · 方式」，便于对照卦象。再下一行为「体用关系 · 起卦时间 → 变卦」，有备注则追加一行（两行截断）。
- 应验状态徽标固定在标题行右侧；名称过长时先收缩标题（`min-width: 0`），不挤走徽标。
- 详情页页头标题同样取卦例名称（最多两行，超出省略）。取的是**已落库**的 `question`——用户在编辑框改完要「保存修改」标题才跟随，避免「改了没保存、标题却已经变了」的错觉。
- 详情 = 排盘结果页布局 + 顶部「所问之事」编辑区 + 底部操作（编辑备注 / 标记应验 / 删除）。
- 删除必须二次确认对话框；确认文案用**卦例名称**而非固定用卦名，确保删掉的就是用户以为的那一条。

### 3.4 学习页

- 起卦方法说明：五个可折叠章节（时间/数字/汉字/声音/随机），内容取自 03 文档规则，含示例。
- 类象速查：上卦选择器 + 类目 Tab（**人伦 / 天时 / 地理 / 身体 / 动物 / 静物 / 性情人事 / 方位 / 时令 / 五味**，共 10 类，类目名称与顺序与 05 文档 §2.2 八卦类象表表头、`packages/knowledge` 的 `TRIGRAM_CATEGORIES` 三方一致）。
- 六十四卦速查：8×8 宫格矩阵（上卦行 × 下卦列），点格进入卦详情。

## 四、视觉规范

### 4.1 色板（浅色主题）

| 语义 | 色值 | 用途 |
| --- | --- | --- |
| 背景 | #FAF7F0 | 宣纸底色 |
| Surface / 卡片 | #FFFFFF | 卡片、对话框 |
| 主文字 | #2B2B2B | 正文 |
| 次要文字 | #8A8578 | 注释、标签 |
| 墨线（主色） | #3A3A3A | 阳爻、主按钮、图标 |
| 朱砂（强调） | #B03A2E | 动爻标记、吉凶徽标、错误 |
| 青灰（辅助） | #6B7B8C | 阴爻断线视觉、次级按钮 |

深色主题：背景 #1C1A17、卡片 #26231F、主文字 #E8E2D5、墨线 #D8D2C4、朱砂 #C9564A。

### 4.2 字体

| 用途 | 字体 | 字号/行高 |
| --- | --- | --- |
| 卦名 / 标题 | 思源宋体（Noto Serif SC，随 APK 打包 SubSet） | 22sp / 1.3 |
| 正文 | 系统默认（HarmonyOS Sans / MIUI 字体兼容） | 15sp / 1.5 |
| 卦符 | 专用绘制（Canvas/自绘 Composable，**不依赖 Unicode 字体渲染**） | 线宽 4dp，断线缺口 8dp |

> 卦符用自绘组件 `TrigramGlyph`（三爻）与 `HexagramGlyph`（六爻）实现，保证所有 ROM 渲染一致；Unicode 卦符 ☰–☷ 仅用于次要场景。Web 端为同名 Vue 组件，用 DOM + CSS 绘制（`border` 画阳爻实线、`background: linear-gradient` 画阴爻断线缺口），**同样不依赖 Unicode 字体渲染**，因此不存在字体缺字或宽度漂移问题。

Web 端字体栈：标题 `"Noto Serif SC", "Songti SC", "SimSun", serif`；正文 `system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`。不打包字体文件（首屏体积优先），缺字时按栈回退。

### 4.3 图标与插画

**界面线性图标**：2dp 描边，与墨线同色（`--c-ink`），统一内联 SVG，不依赖图标字体。

**品牌图标**（`apps/web/public/`，两种形态各有其用）：

| 文件 | 形态 | 用途 |
| --- | --- | --- |
| `icon.svg`、`favicon-32.png`、`apple-touch-icon.png`、`icon-192.png`、`icon-512.png` | **印章**：朱砂底（`#b03a2e`）+ 白文竖排篆书「觀梅」，圆角 140/1024 | 浏览器标签图标、页头 / 侧栏品牌标；192 / 512 为后续 PWA manifest 与 Android 图标预留 |
| `mark.svg` | **纯字标**：朱文竖排篆书「觀梅」，透明底 | 设置面板「关于」区（该处尺寸 84px，字形看得清） |

- 字形为**小篆（玉箸篆）**：线条等粗、圆转匀称。「观梅」在小篆中写作**「觀梅」**——篆书早于简化字，故用正体。
- **标签图标为什么用印章形态而非纯字标**：字块长宽比 1:2.82（竖排两字），纯字标在 16–32px 下糊成一团，且深色标签栏下朱砂对比不足；印章自带底色，16px 仍是可辨识的朱印方块，且明暗主题下表现完全一致。
- 小尺寸已逐一目视确认：印章在 16 / 24 / 32 / 48 / 64px × 宣纸底 / 深色底 / 纯白底共 15 组组合下均成立。
- **来源与授权**：字形由 AI 生成后**矢量化**（potrace 轮廓拟合），**不依赖任何第三方字体**，故无字体授权约束（开源篆书字体要么字数不足，如霞鹜篆书当前仅 45 字；要么为 CC BY-ND，禁止演绎）。矢量轮廓与原位图 **IoU = 0.9587**，接入 `test:runtime` 自检门禁（阈值 > 0.95）。
- 尺寸约定：`icon.svg` viewBox 1024×1024；`apple-touch-icon.png` 铺满宣纸底（iOS 不渲染透明，透明会被填成黑色）。品牌标显示尺寸：顶栏 30px、侧栏 36px。
- Android 端 App 图标沿用同一形态（朱砂底 + 白文篆书），按 mipmap 密度切图。

## 五、交互细节

| 场景 | 交互 |
| --- | --- |
| 起卦成功 | 结果页从底部滑入；卦符六爻自上而下**逐爻浮现**（每爻 80ms，共 ~480ms），动爻圆点最后弹入 |
| 保存卦例 | Snackbar「卦例已保存」，带「查看」动作 |
| 删除卦例 | 二次确认对话框，明确显示卦名与时间 |
| 声音起卦计数 | 每次点按按钮缩放动画 + 轻微触感反馈（HapticFeedback） |
| 数字输入 | 数字键盘，禁止负数/小数；超长输入实时提示上限 |
| 手动修正农历 | 时间起卦页点农历标签 → 底部弹层（农历日期 + 时辰选择器） |
| 错误状态 | 统一错误卡样式（青灰边框），文案给原因 + 建议（如「该字未收录笔画，请手动输入」） |

## 六、无障碍与适配

### 6.1 通用无障碍

| 项 | 要求 |
| --- | --- |
| 屏幕阅读器 | 卦符组件提供可读名称，如「本卦水风井，上卦坎下卦巽，第一爻动」（Android 走 `contentDescription`，Web 走 `aria-label`） |
| 触控目标 | 最小 48 × 48（Android dp / Web px） |
| 动效降级 | 尊重系统「减少动画」设置（Android `AnimatorDurationScale`，Web `prefers-reduced-motion`） |
| 字体缩放 | 支持 1.0–1.3 系统字体缩放不破版（Web 端即浏览器字号放大，须用相对单位 `rem` / `em` 而非固定 px 排版正文） |

### 6.2 Web 端自适应（断点与令牌）

| 视口 | 断点 | 布局 | 说明 |
| --- | --- | --- | --- |
| 移动 | < 900px | 顶部栏 + 底部 3 Tab；内容区单列全宽；主按钮 `position: sticky` 贴底 | 375 / 414px 下不得出现横向滚动条 |
| 桌面 | ≥ 900px | 左侧栏 232px + 内容区居中，宽度上限 1080px | 三卦并排按 1.35 : 1 : 1 分配 |

设计令牌全部落为 CSS 自定义属性（定义在 `apps/web/src/styles/tokens.css`），主题切换只改 `<html data-theme>` 一个属性：

| 令牌 | 值（浅色） | 对应本文件章节 |
| --- | --- | --- |
| `--bg` | #FAF7F0 | §4.1 背景 |
| `--surface` | #FFFFFF | §4.1 Surface |
| `--ink` | #3A3A3A | §4.1 墨线（主色） |
| `--cinnabar` | #B03A2E | §4.1 朱砂（强调） |
| `--slate` | #6B7B8C | §4.1 青灰（辅助） |
| `--nav-h` | 58px | §二 底部 Tab 高度 |
| `--sidebar-w` | 232px | §二 桌面侧边栏宽度 |
| `--content-max` | 1080px | §6.2 桌面内容区上限 |

深色主题令牌值同 §4.1，由 `data-theme="dark"` 覆盖同名变量；首屏在样式加载前由 `index.html` 内联脚本按本地设置写入 `data-theme`，避免浅→深闪白。

### 6.3 Android 端适配

| 项 | 要求 |
| --- | --- |
| 折叠屏 / 平板 | 结果页在展开态改为横向三栏（本 / 互 / 变卦各占一栏） |
| 横竖屏 | 排盘页竖屏为主；横屏时结果页内容区限宽居中，不拉伸卦符 |
