## 二、金标准算例（必须最先通过的用例）

### 2.1 算例 A：时间起卦

| 项 | 值 |
| --- | --- |
| 输入 | 农历 2026 年（丙午，年支午=7）八月十五日 午时（H=7） |
| 中间量 | S1 = 30，S2 = 37 |
| 上卦 | 30 mod 8 = 6 → 坎 |
| 下卦 | 37 mod 8 = 5 → 巽 |
| 动爻 | 37 mod 6 = 1 → 初爻 |
| 本卦 | 水风井（坎上巽下） |
| 变卦 | 水天需（坎上乾下） |
| 互卦 | 火泽睽（本卦六爻自下而上 = 巽[0,1,1] + 坎[0,1,0] = [0,1,1,0,1,0]；第 2,3,4 爻 [1,1,0] = 兑（互下卦）、第 3,4,5 爻 [1,0,1] = 离（互上卦）→ 离上兑下 = 火泽睽。**v1.4 更正**：泽火革为兑上离下，与「二三四爻为互下卦」规则不符；通行口径经「既济互未济」验证） |
| 体用 | 体坎（水）、用巽（木） |
| 生克 | 坎水生巽木 → 体生用 → 小凶 |

> 注：算例 A 的互卦以程序推导结果为准，录入测试断言前先用 03 文档 §3.4 规则手工推演一遍并双人核对，避免「拿结果凑结果」。

### 2.2 算例 B：汉字笔画起卦

| 项 | 值 |
| --- | --- |
| 输入 | 「梅」（繁体 11 画）、「花」（繁体 8 画），起卦时刻秒钟数 S=6 |
| 上卦 | 11 mod 8 = 3 → 离 |
| 下卦 | 8 mod 8 = 0 → 取 8 → 坤 |
| 动爻 | (11 + 8 + 6) = 25 mod 6 = 1 → 初爻 |
| 本卦 | 火地晋（离上坤下） |
| 变卦 | 火雷噬嗑（离上震下） |
| 互卦 | 水山蹇（坎上艮下；v1.4 更正，见 03 文档 §3.4 口径更正） |
| 体用 | 体离（火）、用坤（土） |
| 生克 | 体生用（火生土）→ 小凶 |

## 五、缺陷等级定义

| 等级 | 定义 | 处理 |
| --- | --- | --- |
| S0 | 起卦结果错误（算法/农历/卦象推导错） | 阻塞发布，立即修复 |
| S1 | 功能不可用、崩溃、数据丢失 | 阻塞发布 |
| S2 | 功能缺陷但有替代路径、UI 严重错位 | 当版本修复或降级下版 |
| S3 | 视觉/文案/体验问题 | 记录择机修复 |

**红线**：任何起卦结果与金标准算例不符即为 S0；农历转换错误视为 S0。

## 六、发布准入标准（DoD）

1. 全部单测通过，domain 覆盖率 ≥ 95%。
2. 金标准算例 A、B 通过；农历对拍 200 条零差异。
3. 兼容性矩阵覆盖完成，无未处理 S0/S1。
4. 知识库校验测试通过（64 卦完整）。
5. APK 权限清单仅含必要权限（不得含 INTERNET，见 NFR-02）。
6. 首启声明页、关于页免责文案走查通过。
