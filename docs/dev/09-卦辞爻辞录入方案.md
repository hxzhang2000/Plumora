## 一、背景与目标

结果页「卦辞 · 爻辞」卡当前为占位文案（`apps/web/src/components/ResultPanel.vue:378-388`）：

> 本卦卦辞与动爻爻辞（九二）属知识库 M1 录入项（见 05 文档 §3.3），需按《周易》通行本录入并两轮人工校对后开放。当前以「卦意关键词 + 类象」作为参考。

学习页 64 卦速查同处占位（`apps/web/src/views/LearnView.vue:116`：「卦辞与爻辞属知识库 M1 录入项，校对完成后开放。」）。知识库侧 `packages/knowledge/src/hexagrams.ts:107-109` 的 `guaci / lines / yongText` 恒为 `null`，并由 `packages/knowledge/test/knowledge.test.ts:148-156` 的守卫断言强制为 `null`（「未校对前保持 null，不得臆造文本」）。

05 文档 v2.0 §3.3 已将下列内容定为 **M1（MVP）一次录入项**：

- 64 卦**卦辞全文**（含「卦名：」前缀）；
- **386 爻辞条目**（384 爻辞 + 用九 + 用六）。

本方案的目标：以 `docs/reference/zy.pdf` 为可机读底稿，完成 M1 全量录入 → 两轮人工校对 → 开放结果页与学习页展示，并使 `npm run verify` 与三份文档自查脚本全绿。

**非目标**：彖传 / 象传 / 文言（05 §3.3 M3，可选）、卦名含义简注与白话参考（M2）。

## 二、源材料选定：zy.pdf 与 yi_ching.pdf 对比

`docs/reference/` 现有两份《周易》原文 PDF，对比如下：

| 维度 | `yi_ching.pdf` | `zy.pdf`（选定） |
| --- | --- | --- |
| 页数 / 体量 | 53 页 / 855 KB | 146 页 / 718 KB |
| 文本层 | ❌ 不可机读：Bullzip 从 Word 打印生成，中文为 Type3 自定义编码、无 ToUnicode 映射，53 页仅提取出 18 个可辨汉字 | ✅ 完全可机读：Type0 CID 字体，全量提取 22632 个汉字，零乱码 |
| 语言 | 繁体（需繁→简转换） | 简体（与 05 §3.1 schema 示例口径一致） |
| 结构标记 | 卦辞/爻辞加粗、《彖》《象》小字混排，需按版式识别切分 | 「第N卦 卦名 卦象组合 上X下Y」「卦名：卦辞」「爻名：爻辞」「用九/用六」「X卦终」纯文本标记，正则即可切分 |
| 提取方式 | 渲染 150 DPI 成图 → OCR / 视觉转写 | `pymupdf` 直接 `get_text()` + 正则解析 |
| 内容 | 纯原文（易学网 eee-learning.com 校对本，王弼注底本） | 纯原文经传合编（卦辞 + 爻辞 + 用九用六 + 彖 + 象 + 文言 + 系辞 + 序卦 + 杂卦），无译文 / 注释混入 |

**选定 `zy.pdf`**，理由：文本层完全可提取（提取零成本、可复现）、已是简体（与 schema 示例一致）、结构标记清晰（正则可解析）、纯原文无混入。`yi_ching.pdf` 文本层不可用，仅作可选的**二级校对参考**（渲染后对异文做视觉比对）。

> ⚠️ `zy.pdf` 是「可机读工作底稿」，**非权威通行本**。05 文档 v2.0 §一 L19 已规定数据来源以《周易》通行本（王弼注 / 十三经注疏系统）为准——异文一律以通行本为准，`zy.pdf` 原字记入校对存疑清单。见 §四。

## 三、文本提取与结构化流程

### 3.1 提取

`pymupdf` 全量文本提取（已验证可行，产出纯文本约 4.9 万字符）。脚本一次性运行，产物不入库，仅作中间态。

### 3.2 切分

按卦头标记切分为 64 卦块。`zy.pdf` 卦头有两种写法（「第N卦」与「《易经》第N卦」），卦尾有「X卦终」标记：

```text
第四十八卦 井 水风井 坎上巽下
  井：改邑不改井，无丧无得，往来井井。汔至，亦未□井，
羸其瓶，凶。
  彖曰：……
  象曰：……
  初六：井泥不食，旧井无禽。
  ……
  上六：井收勿幕，有孚无吉。
  井卦终
```

### 3.3 逐卦解析

每卦块按行解析，对齐 05 文档 v2.0 §3.1 schema：

| 字段 | 解析规则 |
| --- | --- |
| `name` / `shortName` / 卦象组合 | 卦头「第N卦 卦名 卦象组合 上卦下卦」拆分；上下卦与 05 §3.2 速查表逐一对照 |
| `guaci` | 「卦名：……」行，**保留「卦名：」前缀**（与 05 §3.1 示例 `井：改邑不改井……` 一致）；跨行合并去多余换行 |
| `lines[1..6]` | 「初九 / 六二 / …… / 上九 / 上六：……」六行；`name` 取爻名，`text` 取爻名「：」之后的正文（**不含爻名前缀**，与 05 §3.1 `lines[].text` 口径一致） |
| `yongText` | 仅乾、坤二卦：「用九：……」/「用六：……」；**不并入 `lines`**（05 §3.4 规则 2：`lines` 恒 6 条） |
| **排除项** | 「彖曰」「象曰」「文言」段一律不入 M1（属 05 §3.3 M3 范围）；「系辞」「序卦」「杂卦」非卦内内容，整体丢弃 |

### 3.4 结构化与完整性自检

按 05 文档 v2.0 §3.1 schema 生成 64 卦 JSON 草稿，并跑程序化自检：

- 64 卦 × 6 爻 = 384 爻辞 + 用九 + 用六 = **386 爻辞条目**；**64 卦辞**；合计 450 条文本；
- 每卦 `lines` 恰 6 条；乾、坤 `yongText` 非空，其余 62 卦为 `null`；
- 卦名、上下卦组合与 05 §3.2 速查表**逐卦逐一对照**（一条不多不少）；
- 爻名与 `index` 匹配（初六↔1、九二↔2 …… 上六↔6）。

## 四、数据口径与异文处理

### 4.1 底本口径与校对基准

**口径**：以《周易》通行本（王弼注 / 十三经注疏系统）为准（05 文档 v2.0 §一 L19），即**阮元校刻《十三经注疏》本《周易正义》**（王弼、韩康伯注，孔颖达疏）。

**校对基准电子版**（dev-time 线上参考，**不入运行时**——产品离线承诺不受影响）：

| 角色 | 电子版 | 底本 | 可机读 | 用法 |
| --- | --- | --- | --- | --- |
| 主用 | 维基文库《周易正义》 `https://zh.wikisource.org/zh-hans/周易正義` | 十三经注疏·周易正义系统（标准分卷、井卦四校验点逐字命中，见 §4.3） | ✅ wikitext 纯文本可提取 | 一校逐字对照的主基准 |
| 对拍 | ctext.org《阮元校刻十三经注疏》本《周易正义》 `https://ctext.org/library.pl?if=gb&res=83519` | 明确＝阮元校刻本（与口径一字不差） | ⚠️ 扫描 + OCR、反爬，仅人眼浏览 | 维基文库本存疑时的权威仲裁 |

> ⚠️ ctext 主站 `ctext.org/book-of-changes` 底本是《武英殿十三经注疏》（**非阮元本**）、且仅经传无注疏，**不作主用**，仅作经传本文的第三交叉源。

`zy.pdf` 作可机读工作底稿，其文本与上述校对基准的差异处一律**以校对基准为准**，`zy.pdf` 原字记入存疑清单。

### 4.2 繁简与标点

`zy.pdf` 已是简体，与 05 §3.1 schema 示例一致，无需繁→简转换。卦辞 / 爻辞末尾句号统一全角；卦辞内分句保留原标点，但去除 `zy.pdf` 跨行断句产生的多余逗号（如井卦卦辞「汔至，亦未□井」的「汔至，」逗号系跨行所致，通行本作「汔至亦未繘井」）。标点风格以 05 文档 v2.0 §3.1 schema 示例为准（如「井洌，寒泉食。」）；校对基准电子版（维基文库本）的标点（如「井洌寒泉，食。」）仅取其**字**、不取其标点。

### 4.3 金标准抽检：井卦异文（口径证据）

井卦（第四十八卦）是 05 §3.1 schema 示例卦、亦是 AGENTS.md 金标准算例（2026-08-15 午时 → 水风井）。抽检 `zy.pdf` 井卦与 05 §3.1 通行本示例，发现 4 处差异：

| 位置 | `zy.pdf` | 通行本（05 §3.1） | 处理 |
| --- | --- | --- | --- |
| 卦辞 | 汔至，亦未**□**井 | 汔至亦未**繘**井 | 缺字 □ = 繘，补字；去跨行逗号 |
| 九三 | 为我**民**恻 | 为我**心**恻 | 异文，以「心」为准 |
| 九五 | 井**冽** | 井**洌** | 异文，以「洌」为准 |
| 上六 | 有孚**无**吉 | 有孚**元**吉 | 疑似错字（《象》曰「元吉在上，大成也」佐证），以「元吉」为准 |

> 仅抽检一卦即发现 4 处异文 / 缺字 / 错字，证明 05 文档 §一「两轮人工校对」**非形式要件**，必须实打实逐字校对。晋卦（火地晋，梅/花金标准算例）同理重点复核。
>
> 上述 4 处通行本正确字（繘 / 心 / 洌 / 元）已用维基文库《周易正义》本逐字验证命中（见 §4.1 校对基准），佐证该电子本即可信的通行本口径。

### 4.4 用九 / 用六

- 乾「用九：见群龙无首，吉。」→ `yongText`；
- 坤「用六：利永贞。」→ `yongText`；
- 其余 62 卦 `yongText` 为 `null`。
