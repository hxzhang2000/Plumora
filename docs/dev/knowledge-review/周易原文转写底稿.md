## 一、使用说明

1. **本底稿为未校对状态，禁止直接入库。** 两轮人工校对完成前，`hexagrams.ts` 的 `guaci / lines / yongText` 必须保持 `null`（`packages/knowledge/test/knowledge.test.ts` 有守卫断言）。
2. **校对对象是「交付层」列。** 「权威层」列仅用于溯源与繁简互校——若两列字面不符（除繁简对应关系外），说明抓取出错，须回查页面。
3. **改写方式**：直接修改「交付层」列文字，并在「存疑 / 校对结论」列记录「原字 → 正字 · 依据」。一校结论标「一校：」，二校标「二校：」。
4. **字段映射**（05 §3.1 schema）：「卦辞」行 → `guaci`（**含**「卦名：」前缀）；「初九…上六」行 → `lines[{index:1-6, name, text}]`，`text` **不含**爻名；「用九 / 用六」行 → `yongText`（仅乾坤二卦），**不并入** `lines`。
5. **标点口径**：句末统一全角句号；卦辞内分句保留语义断句，去除跨行断句产生的多余标点；风格以 05 §3.1 示例为准（09 §4.2：取字不取标点）。
6. ⚠️ **程序化自检只证明结构完整、无污染、无已知注泄漏，不证明逐字正确。** 逐字正确性只能由人工校对给出。
