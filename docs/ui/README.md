## 三、技术要点

- 农历转换内嵌 solarlunar（MIT，1900–2100 数据表），已通过金标准验证：2026-09-25 = 丙午年八月十五。
- 算法与 03 文档 v1.6 完全一致：余0取8/6、两字动爻含秒钟数、晚子时按次日子时、闰月按本月份数、**年界取农历年（正月初一为界，非立春干支年）且标签干支年与算法年支同源**、互卦口径（二三四爻为互下卦，既济互未济验证）。
- 主题实现：CSS 变量 + `data-theme` 切换，色板取自 06 文档（宣纸底/墨线/朱砂/青灰）。

原型只有**一个**测试文件 `build/smoke.test.js`（jsdom 单进程跑完整原型），共 **42 条断言全通过**：

| 分组 | 覆盖内容 |

| 算法口径回归（后 12 条） | 卦代码补零（C-2）、年界口径与标签同源（C-1）、闰月标签不出现「闰闰」（D-1） |

- **回归测试命令**（必须显式指定 NODE_PATH，否则报 `Cannot find module 'jsdom'`）：

```bash
cd docs/ui
NODE_PATH="C:/Users/hxzha/.workbuddy/binaries/node/workspace/node_modules" \
  node build/smoke.test.js
```

- **改动 build/ 下的源文件后必须先重新打包，否则单文件 HTML 仍是旧代码**（这正是 D-1「闰闰六月」漏网的原因）：

```bash
python docs/ui/build/pack.py     # 仓库根目录执行
```

> jsdom 装在**隔离的 Node workspace**（`C:/Users/hxzha/.workbuddy/binaries/node/workspace`，注意是 `.workbuddy` 而非 `.workbuddy-ai`），未污染全局环境。

## 五、已知边界（原型口径）

1. 笔画表内置约 120 个常用字；未收录字走「手动输入笔画」兜底（与 03 文档 §6.4 一致），正式版需扩充至 8000 字。
2. 卦辞/爻辞未内置（知识库 M1 录入项，05 文档 §3.3），当前以卦意关键词 + 类象呈现。
3. 分享为「复制排盘文本」；图片分享属 M3 范围。
