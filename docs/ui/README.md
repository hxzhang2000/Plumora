## 三、技术要点

- 农历转换内嵌 solarlunar（MIT，1900–2100 数据表），已通过金标准验证：2026-09-25 = 丙午年八月十五。
- 算法与 03 文档 v1.3 完全一致：余0取8/6、两字动爻含秒钟数、晚子时按次日子时、闰月按本月份数、互卦口径（二三四爻为互下卦，既济互未济验证）。
- 主题实现：CSS 变量 + `data-theme` 切换，色板取自 06 文档（宣纸底/墨线/朱砂/青灰）。

## 四、测试结论

- core.js 单测：30 断言全通过（时间/数字/汉字/声音起卦、互变卦推导、五行生克 25 组合、晚子时、笔画表、64 卦完整性）。
- jsdom 冒烟：25 断言全通过（页面加载、四种起卦实操、保存卦例、列表渲染、学习页交互、设置切换）。
