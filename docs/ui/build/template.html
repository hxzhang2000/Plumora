① 时间起卦（年月日时）
年取地支序数（子1…亥12），月日取农历数，时取时辰序数（子1…亥12）。
上卦 (年＋月＋日) mod 8；下卦 (年＋月＋日＋时) mod 8；动爻 (年＋月＋日＋时) mod 6。余0取8/取6。23点后按次日子时。
② 数字起卦
两数：上 n1 mod 8，下 n2 mod 8，动 (n1＋n2) mod 6。
一数：上 n mod 8，下与动以 (n＋时辰数) 计。
③ 汉字笔画起卦
两字：上 A mod 8，下 B mod 8，动 (A＋B＋秒钟数) mod 6（余0取6）。
一字：上 T mod 8，下 (T＋时辰) mod 8，动 (T＋时辰) mod 6。同一卦内笔画标准须统一。
④ 声音（点数）起卦
闻声计数 c1、c2：上 c1 mod 8，下 c2 mod 8，动 (c1＋c2) mod 6。
⑤ 体用生克（断卦核心）
动爻所在之卦为用，静者为体。用生体大吉；体克用小吉；比和吉；体生用小凶；用克体大凶。再参互卦看过程、变卦看结局，结合卦象类象综合判断。
